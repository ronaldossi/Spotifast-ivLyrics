# 검색 시작 화면

검색어가 비어 있으면 최근 검색어와 함께 추천 곡 카드, 최근 재생 목록을 표시합니다.
추천 목록이 없으면 자주 들은 곡을 사용합니다. 최근 재생은 기기의 재생 기록과
기존 홈 화면 데이터를 합치며, 같은 곡은 한 번만 표시합니다.
아직 곡 데이터가 없을 때는 장르별 검색 버튼을 제공합니다.

최근 검색 제목 옆의 **전체 삭제**는 검색어 기록만 지웁니다.
재생 기록, 추천 목록, 현재 재생은 유지하며 삭제 결과는 기존 설정 저장 경로에 저장합니다.
카드를 누르면 표시된 카드 목록을 선택한 곡부터 재생합니다.
빈 검색 화면의 데이터는 홈 화면의 기존 요청·캐시를 재사용합니다.

한국어 설정에서는 제목과 장르 버튼도 한국어로 표시합니다.
곡명과 가수명은 원래 메타데이터를 보존하며, 한글도 기존 글꼴과 줄임 처리를 사용합니다.

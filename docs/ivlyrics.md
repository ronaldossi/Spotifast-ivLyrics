# Spotifast + ivLyrics (네이티브 통합판)

이 로컬 수정판은 Spicetify 없이 Spotifast 안에서 ivLyrics의 주요 가사 기능을
사용합니다. 기존 Spotify/Spicetify 설치나 그 설정은 변경하지 않습니다.
음악 재생에는 원본 Spotifast와 동일하게 Spotify Premium이 필요합니다.

## 사용하기

미니 플레이어와 전체화면의 긴 곡 제목은 처음에 1.5초 기다린 뒤 천천히 왼쪽으로 이동합니다.
단, 전체화면에서 공백을 포함해 30자 이하인 제목은 움직이지 않고 한 줄에 전부 표시합니다.
앨범 너비에 제한하지 않고 정보 영역의 여유 폭을 먼저 사용하며, 그래도 공간이 부족할 때만
글자 크기를 줄입니다. 30자를 넘는 제목과 미니 플레이어는 표시 폭을 넘을 때 기존 이동 동작을 사용합니다.
끝까지 보이면 2초 기다리고 처음으로 돌아와 반복합니다. 짧은 제목은 움직이지 않으며,
곡이나 창 폭이 바뀌면 처음부터 시작합니다. 제목 위에 마우스를 올리거나 선택하는
동안에는 멈춰 읽고 복사할 수 있습니다. 가사 미니 화면, 앨범 미니 화면과 전체화면에 적용합니다.
트레이에서 창을 다시 열 때 앨범 배경은 새 창에 맞게 다시 생성합니다.
전체화면에서 가사를 클릭한 뒤 휠로 스크롤해도 앨범과 재생 컨트롤 위치는 유지됩니다.
앨범과 가사를 나란히 표시할 때 가사가 흐려지는 위·아래 범위는 앨범 상단과
재생 컨트롤 하단에 맞춥니다. 창 크기와 좌우 배치를 바꾸면 효과 범위도 함께 맞춰집니다.
Windows 전체화면은 실제 최대화 상태를 해제하고 작업표시줄을 포함한 모니터 전체 영역을
사용합니다. 전체화면을 나가면 이전 최대화 상태로 복원합니다.

한국어 시스템에서는 메뉴와 설정이 자동으로 한국어로 표시됩니다.
**설정 → 이 컴퓨터에서 재생 → 출력 오디오 장치**에서 시스템 기본값 또는 연결된
출력 장치를 선택할 수 있습니다. **적용 후 재생 다시 시작**을 누르면 장치가 변경되며
선택은 다음 실행에도 유지됩니다. 새 장치를 연결했다면 옆의 새로고침 버튼을 누릅니다.
저장한 장치를 사용할 수 없으면 시스템 기본 장치를 사용합니다. 이 설정은 이 컴퓨터의
로컬 재생에 적용되며 Spotify Connect의 다른 기기 출력은 바꾸지 않습니다.
새 프로필은 ALSong을 선택하고, 볼륨 50%와 가사 패널 폭 343px로 시작합니다.
AI는 계속 기본 OFF이며 계정, API 키와 곡별 기록은 기본값에 포함하지 않습니다.
Windows의 설정·기록·캐시는 `paolino` 하위 폴더에서 `spotifast` 하위 폴더로
자동 이전합니다. 기존 앱을 종료한 뒤 새 버전을 실행하면 설정을 그대로 이어 씁니다.
다른 언어로 표시되면 **Settings → Appearance → Language → 한국어**를 선택하세요.
한국어·일본어·영어의 기본 화면과 가사에는 **Pretendard JP 1.3.9**를 내장해
일반·중간·굵은 글씨에 적용했습니다. 글꼴을 따로 설치할 필요가 없습니다.
운영체제 메뉴의 글꼴은 해당 시스템을 따릅니다.

기본 UI는 밝은 화면의 진회색과 어두운 화면의 흰색·연회색을 강조색으로 사용하는
무채색 팔레트입니다. 앨범 배경의 색은 유지하며, 버튼과 선택 표시는 중립색을 사용합니다.

1. 음악을 재생하고 하단 **전체화면 아이콘**, **F11**, 또는 **L**을 누릅니다.
   기본 전체화면은 ivLyrics입니다. 같은 버튼이나 단축키로 돌아옵니다.
2. **Esc**는 ivLyrics 설정창이나 알송 후보창을 먼저 닫습니다. 다시 누르면
   전체화면을 종료하고 이전 창 상태로 돌아옵니다.
3. 옆쪽 가사 패널은 **Shift+L** 또는 가사 버튼 우클릭 → **Lyrics panel**로 엽니다.
   오른쪽 패널 상단의 **가사 · 재생 대기열 · 최근 기록** 탭으로 전환합니다.
   전체화면 진입은 하단 재생 바의 버튼을 사용합니다.
4. 가사의 한 줄을 누르면 해당 시각으로 이동합니다. 자동 따라가기가 멈췄으면
   **Follow**로 다시 시작합니다.

## 알송과 가사 선택

- **곡별 가사 설정**에서 현재 곡의 제공자를 바꾸면 즉시 자동 저장합니다.
  가사 화면의 제공자 팝업도 같은 곡별 설정을 사용합니다. 알송 가사 선택과
  싱크 보정값도 함께 기억하며, 곡을 다시 재생하거나 앱을 다시 실행해도 유지됩니다.
  **다른 곡의 기본 제공자**는 별도로 저장한 선택이 없는 곡에 적용합니다.
  곡별 **자동** 선택은 기본 제공자와 무관하게 설정된 제공자 순서대로 조회합니다.
- **가사·번역 캐시 초기화**는 다운로드한 가사와 AI 번역 캐시만 지웁니다.
  곡별 제공자·알송 선택·싱크 보정값, API 키, 오디오·이미지 캐시는 유지합니다.
  진행 중인 가사·번역 요청이 끝난 뒤 초기화하며, 결과나 오류를 버튼 아래에 표시합니다.
  현재 표시 중인 가사는 그대로 두고, 다음 조회부터 필요한 내용을 다시 가져옵니다.
  AI가 켜져 있으면 이후 번역 요청 시 API 사용량이 다시 발생할 수 있습니다.

- 기본 순서는 **ALSong → Spotify → LRCLIB**입니다. 메인 설정의 **ivLyrics 설정**이나
  가사 화면의 톱니바퀴에서 **가사 제공자 순서** 카드의 위·아래 버튼으로 바꿉니다.
  **자동**은 카드 순서대로 검색하며, 제공자를 직접 고르면 그 제공자만 사용합니다.
  가사 화면의 현재 제공자 팝업에서도 즉시 선택할 수 있습니다. 예전 ‘알송 우선’이
  꺼져 있던 설정은 Spotify → LRCLIB → ALSong 순서로 읽습니다.
- 알송 자동 조회는 제목과 가수 별칭이 일치하고, **가사 본문에 한글이 있는** 후보만
  채택합니다. 자동 선택에서는 곡 길이 차이가 60초 이상이면 제외합니다.
  알송 재생 시간이 없으면 마지막 가사 시각을 비교하고, 둘 다 없으면 길이를
  비교하지 않습니다. 영문/한글 병기와 공동 가수 표기를 지원합니다.
- **알송 가사 후보**는 왼쪽 검색 목록, 오른쪽 선택한 가사의 2열 화면입니다.
  각 열은 따로 스크롤합니다. 페이지를 넘기며 원문과 타임스탬프를 미리 보고
  **Use these lyrics**를 누르면 곡별로 기억합니다. 수동 선택은 한글 조건을
  유지하고 길이 제한은 적용하지 않습니다.
  제목이나 아티스트를 수정하여 직접 검색할 수 있으며 둘 중 하나만 입력해도 됩니다.
  수동 검색은 다른 표기의 후보도 보여주고, 미리 확인한 후보를 현재 곡에 연결합니다.
  한 번 조회에 실패해도 제공자를 알송으로 선택하면 후보 버튼을 다시 사용할 수 있습니다.
  곡 제목과 아티스트명은 드래그하여 선택하고 복사할 수 있습니다.
- **Restore automatic selection**은 이 곡의 저장된 후보를 해제하고 자동 제공자 선택으로 돌아갑니다.
- 자동 검색은 첫 페이지에서 최대 세 후보를 확인합니다. 적합한 후보가 없을
  때만 제목 단독 검색을 한 번 더 합니다. 네트워크 오류를 자동 재시도하지
  않습니다. 자동 조회 실패 시 안내를 표시하고 다른 제공자를 시도하며, 수동으로
  고른 후보의 실패는 가사를 조용히 바꾸지 않고 오류로 표시합니다.

## 번역과 발음

1. 가사 화면의 **톱니바퀴 → 번역 및 발음**으로 설정을 엽니다.
2. Gemini, OpenAI, Claude, Groq, OpenRouter 중 제공자를 선택하고, 해당 API 키로
   이용 가능한 대화 모델의 **Model ID**를 입력합니다. 해당 제공자의 채팅 API와
   JSON 출력을 지원하는 모델을 사용하세요.
3. 번역 언어와 발음 표기 방식을 지정합니다. 기본값은 `Korean`, `Korean Hangul`이며
   로마자 발음을 원하면 발음 표기를 `Latin`으로 바꿀 수 있습니다.
4. **Apply settings**를 누른 다음 API 키를 입력합니다. **Save API key**로 운영체제의
   자격 증명 저장소에 보관합니다. 저장하지 않은 키는 현재 실행에서만 사용합니다.
   빈 키를 저장하면 해당 제공자의 저장된 키를 삭제합니다.
5. **번역 및 발음**의 **AI ON(켜짐)** 스위치를 켜고 **설정 적용**을 누릅니다. 기본값은 OFF입니다.

설정 입력 중에는 번역 요청을 보내지 않습니다. 변경 사항을 적용했을 때와
AI를 켠 상태에서 곡/가사가 바뀔 때 요청합니다. 실패 시 원문을 유지하고
**Retry translation**을 제공합니다. 모델 ID는 자동으로 대체하지 않습니다.
모델이 줄 번호를 누락하거나 중복시키면 잘못된 싱크로 표시하지 않고 오류를 냅니다.

번역·발음은 원문 아래에 표시되며 각각 숨길 수 있습니다. AI OFF에서는
캐시를 포함한 번역 표시와 새 요청을 모두 중단합니다. 이미 제공자에게 도착한
요청/과금은 되돌릴 수 없지만, 늦게 도착한 결과는 화면에 반영하지 않습니다.
기존 알송 원문에 들어 있는 번역과 발음은 AI OFF여도 유지됩니다.

## 싱크와 글자 크기

톱니바퀴의 **ivLyrics 설정**은 모든 항목을 한 페이지에 담았습니다.
탭이나 사이드 메뉴 없이 스크롤하며, 창의 최대 폭은 720px입니다.
팝업 아래의 초기화·설정 적용 버튼은 스크롤과 관계없이 유지됩니다.
미니 플레이어에서는 설정을 독립된 창으로 열고, 화면의 여유 공간에 따라
플레이어 왼쪽이나 오른쪽에 배치합니다. Windows에서는 내부 제목과 닫기 버튼을 사용합니다.
메인 앱 설정에도 같은 전체 항목이 직접 표시되며 별도의 창을 열 필요가 없습니다.

- **가사**: 제공자 선택·검색 순서와 현재 곡의 알송 후보.
- **번역 및 발음**: AI 사용, 제공자·모델·언어·API 키, 번역/발음 표시.
- **화면 설정**: 가사 정렬, 글자 배율, 줄 간격, 비활성 가사 농도,
  번역/발음 크기, 알송 두/세 줄 크기, 앨범 이미지 배경과 어둡기.
- **전체화면 가사**: 1열/2열, 앨범과 가사 좌우 반전, 앨범 이미지·곡 정보·앨범명
  표시, 앨범 크기·모서리, 제목·아티스트 크기, 재생 버튼 위치와 진행/음량 표시.

옵션을 바꾼 뒤 **설정 적용**으로 저장합니다. 적용 전에 창을 닫으면 편집 내용을
취소합니다. 화면 설정의 **초기화**는 화면·글자 설정의 편집값만 기본값으로 되돌리며,
API 키, 제공자 설정, 곡별 가사 선택과 싱크를 지우지 않습니다.

전체화면은 기본적으로 앨범과 곡 정보를 왼쪽 중앙, 가사를 오른쪽 중앙에 배치합니다.
현재 가사는 세로 중앙을 따라갑니다. 앨범 아래에는 진행 막대, 재생 조작,
음량 막대, 좋아요·미니 플레이어·대기열·기기·전체화면 버튼이 차례로 놓입니다.
전체화면 버튼은 메인 화면과 미니 플레이어에서도 도구 모음 맨 오른쪽입니다.
음량 막대 자체의 중심이 앨범과 재생 버튼의 중심에 맞고 음소거 버튼은 왼쪽에 있습니다.
왼쪽 가장자리에 포인터를 가져가면 재생목록이 왼쪽에서 나타납니다.
포인터가 목록을 벗어나면 닫히며, 하단 재생목록 버튼이나 **Q**로 열면 고정됩니다.
목록은 가사 위에 겹쳐 표시되므로 가사 배치와 중심 위치는 바뀌지 않습니다.
미니·전체화면 모두 흰색 카드 대신 같은 앨범 배경이 이어져 보이며,
목록 뒤의 가사는 완전히 가리고 밝은 글자와 버튼으로 표시합니다.
대기열의 모서리는 24px로 둥글게 표시합니다.
상단의 **재생 대기열 · 최근 기록** 탭은 메인 오른쪽 패널과 같은 선택 표시를 사용합니다.
최근 기록에서는 이 컴퓨터와 Spotify의 재생 기록을 함께 보고 곡을 다시 재생할 수 있습니다.
미니 플레이어와 전체화면 모두 같은 목록을 사용하며, 두 탭의 스크롤 위치는 각각 유지합니다.
열 때마다 최신 대기열을 요청하며, 응답을 기다리는 동안 현재 목록을 유지합니다.
재생 중인 기기가 없다면 빈 응답으로 저장된 대기열을 지우지 않습니다.
닫기나 **Esc**로 목록부터 닫을 수 있습니다.

상단 도구는 포인터를 해당 영역에 올리거나 Tab 키로 접근하면 나타납니다.
톱니바퀴 바로 오른쪽의 현재 제공자 버튼은 버튼에 고정된 간단한 설정을 엽니다.
타이밍의 `0 ms`는 포인터를 올렸을 때 강조됩니다. 드래그는 25ms 단위이며,
직접 숫자를 입력할 수도 있습니다. 위아래 경계에서는 배경 블록 없이
글자 자체의 투명도가 부드럽게 낮아집니다. 두 줄과 세 줄 설정에는 각각 크기 슬라이더·굵기·미리보기가 있습니다.
기본 크기는 두 줄 `36 / 38`, 세 줄 `36 / 20 / 38`px입니다. 첫 줄은 중간 굵기,
나머지 줄은 약간 굵게 표시합니다. 기존에 저장한 스타일은 유지하며 **초기화**로
새 기본값을 적용할 수 있습니다. 배경 어두움은 `0.050`입니다.

**가사 묶음 간격**은 서로 다른 시각의 가사 사이 여백을 0~120px로 조절합니다.
기본값은 40px이며 패널·전체화면·플로팅 가사에 공통 적용합니다.
같은 시각에 묶인 원문·발음·번역의 내부 간격과는 별개입니다.
**두 줄 가사**에는 1–2행, **세 줄 가사**에는 1–2행과 2–3행 간격을
각각 0~60px로 설정할 수 있습니다. 두 줄 기본 간격은 4px, 세 줄은 3px와 3px이며 미리보기에도 적용합니다.
자동 글자 맞춤으로 글자가 축소되면 행 간격도 같은 비율로 줄어듭니다.
여러 줄 가사 사이의 한 줄 가사는 가장 가까운 두/세 줄 묶음의 첫째 줄 크기와
굵기를 따릅니다. 곡 전체가 한 줄 가사뿐이면 기본 글자 설정을 사용합니다.

일반 미니 플레이어는 재생 제어를 항상 표시하며 아티스트명 아래에 여유를 둡니다.
플로팅 가사의 작은 앨범과 곡 정보는 상단에 배치합니다. 곡 정보 위쪽과
대기열 사이 바깥 여백은 각각 16px입니다. 하단에 마우스를 올리면
재생 시간바와 제어 버튼이 약 0.16초 동안 부드럽게 올라오고, 벗어나면 내려갑니다.
접힌 상태에서도 시간바는 최하단에 남습니다. Tab 키로도 제어 버튼을 펼칠 수 있습니다.
미니 플레이어에서는 이전 가사 한 묶음이 먼저 보이고, 그 아래에 현재 가사가 옵니다.
곡의 첫 가사에는 이전 묶음을 만들지 않습니다. 가사의 영역·스크롤·
기준 위치는 바뀌지 않으며 조작부가 가사 위에 겹쳐 표시됩니다.
조작부 뒤에는 동일한 앨범 배경을 다시 그려 가사가 비치지 않습니다.
플로팅 가사 창은 폭 900px·높이 560px 이상이고 가로/세로 비율이 1.4 이상이면
전체화면과 같은 앨범·가사 2열 배치로 전환됩니다. 다시 좁히면 세로 배치로 돌아갑니다.
**2열 레이아웃** 설정을 끄면 자동 전환도 하지 않습니다.
MilkDrop 기능과 설정·단축키·실행 코드·빌드 의존성은 제거했습니다.
기존 사용자 프리셋 파일은 삭제하지 않습니다.

**가사 자간**은 -2~12px 범위에서 조절하며 기본값은 -0.5px입니다.
미리보기와 실제 가사에 같은 자간을 적용합니다.
**가사 공간에 맞춰 글자 크기 자동 조절**은 기본 ON입니다.
플로팅 창을 줄이면 모든 행의 크기와 간격을 함께 줄여 행별 비율을 유지합니다.
자동 조절을 켜면 한두 단어만 넘치는 가사 묶음은 최대 20% 더 줄여 한 줄에 맞춥니다.
원문·발음·번역의 글자 크기 비율과 행 간격은 함께 줄어듭니다. 다른 묶음은 그대로이며,
20% 넘게 줄여야 하는 긴 문장은 기존 크기로 줄바꿈합니다. 자동 조절을 끄면 이 보정도 끕니다.
전체화면의 현재 가사는 세로 중앙보다 위에 표시합니다. 재생을 일시 정지하면
가사 텍스트를 드래그해 선택하고 Ctrl+C로 복사할 수 있습니다.
메인 플레이어의 가사 맨 위에서는 첫 묶음의 원문·발음·번역에 상단 페이드를
적용하지 않습니다. 첫 묶음을 위로 스크롤해 넘기면 기존 페이드가 다시 적용됩니다.
사이드 패널과 플로팅 가사에서 상단 버튼·하단 컨트롤을 제외한 실제 가사 영역의
폭과 높이로 공통 배율을 정합니다. 기준 영역은 520×680px이며, 설정한 글자 크기는
상한으로 사용합니다. 창을 줄이면 글자와 간격이 함께 줄고, 길거나 짧은 가사로
바뀌어도 글자 크기는 유지합니다. 긴 행은 줄바꿈하며 행별 크기 비율을 유지합니다.
OFF에서는 원래 크기로 줄바꿈합니다.
이 자동 맞춤은 전체화면 가사에는 적용하지 않습니다.

가사 화면과 미니 플레이어의 배경은 흐린 앨범아트입니다.
**앨범 이미지 배경**으로 켜고 끕니다. **앨범 대표색 그라디언트**는 ivLyrics 설정창의
배경에만 적용하며, 두 옵션은 독립적입니다. 메인 앱의 기존 앨범색 설정은 유지합니다.
앨범 그림자는 더 넓고 옅게 퍼집니다. 하단 재생 바의 스펙트럼·파형 효과와
해당 설정은 제거했으며 실제 음질을 조절하는 이퀄라이저는 유지합니다.

창은 기본적으로 시스템 제목 표시줄 없이 표시됩니다. 오른쪽 원형 버튼은 왼쪽부터
최소화·최대화/복원·닫기입니다. 기존 설정은 처음 한 번 이 창 모양으로 전환되며,
이후 사용자가 선택한 제목 표시줄 설정은 유지합니다.
미니 플레이어의 설정 톱니바퀴는 창 제어 버튼 아래 오른편에 있으며,
상단에 마우스를 올리거나 Tab으로 접근할 때 함께 나타납니다.
Windows 미디어 패널이 앱 이름을 찾을 수 있도록 시작 메뉴의
`Spotifast/Spotifast.lnk`에 앱 식별자를 등록합니다. 휴대용 실행 파일을 옮기면
다음 실행 때 바로가기 경로도 갱신합니다.
Windows 11의 일반 창은 시스템의 둥근 모서리와 그림자를 사용합니다.
전체화면에서는 1px 상단 틈이 생기지 않도록 창 그림자만 끕니다.
Winamp 스킨의 버튼·설정·단축키·스킨 파일 드롭 진입은 제거했습니다.
기존에 저장된 스킨 파일은 삭제하지 않습니다.

이 로컬 수정판에서는 자동 업데이트 확인·다운로드 및 수동 업데이트 확인을
제거했습니다. 정보 카드의 제작자 링크와 간결한 목록 옵션도 제거했으며,
기존 간결한 목록 설정을 읽어도 일반 목록으로 표시합니다.
배포에 포함되는 원본 라이선스와 저작권 고지는 유지합니다.

## 미니 플레이어와 아이콘

전체화면 버튼 바로 옆의 모니터 아이콘을 누르면 작은 미니 플레이어로 전환합니다.
재생 상태를 유지하며 앨범·곡 정보, 재생·탐색·음량과 기존 조작 버튼을 제공합니다.
같은 버튼이나 **Esc**로 원래 창 크기와 화면으로 돌아갑니다.
미니 플레이어에서 전체화면을 선택하면 전체화면 가사로 이동합니다.
재생목록 버튼은 현재 미니 창 안에서 목록을 아래에서 위로 펼칩니다.
기존 Winamp 스킨과는 별개의 네이티브 화면입니다.

앨범아트를 누르면 같은 창 크기에서 **플로팅 가사**로 전환합니다.
위쪽의 작은 앨범·곡 정보, 중앙 가사, 아래쪽 재생·음량·기능 버튼의 한 열 배치입니다.
지원되는 운영체제에서는 다른 창 위에 표시합니다. 작은 앨범을 다시 누르거나
**Esc**를 누르면 앨범 중심의 미니 플레이어로 돌아갑니다.
두 미니 화면의 제목 표시줄 버튼은 상단에 포인터를 올리거나 Tab으로 접근할 때만
나타납니다. 일반 메인 창의 버튼 표시 방식은 바뀌지 않습니다.
하단 **PiP · 항상 위에 표시** 버튼으로 창 고정을 켜거나 끌 수 있습니다.
별도 영상 창을 만드는 기능은 아닙니다. 미니 플레이어를 나가면 고정을 해제합니다.

앱 아이콘은 사용자 요청에 따라 Spotify 원형 파형을 짙은 회색 `#303030`과
흰색으로 표시합니다. 실행 파일·창·트레이·앱 내부 로고가 같은 SVG를 사용합니다.
제목 표시줄 버튼은 최소화(노랑) → 최대화/복원(초록) → 닫기(빨강) 순서입니다.

- 가사 화면의 **ms** 값을 조절하면 곡별로 저장됩니다. 양수는 가사를 더 늦게,
  음수는 더 일찍 표시합니다. 범위는 ±60초, **Reset**은 0으로 복원합니다.
  가사 클릭 이동에도 같은 오프셋을 적용합니다.
- **Lyric text scale**은 패널/전체화면의 글자 크기를 조절합니다.
- **Two-row lyrics / Three-row lyrics**는 알송의 명시적인 줄바꿈에만 적용됩니다.
  0은 기본 크기를 따르고, 지정한 크기는 12~120px 범위입니다. 자동 줄바꿈이나
  다른 제공자의 가사, AI 번역에는 이 규칙을 적용하지 않습니다.

## 저장과 통신

- 비밀이 아닌 설정, 곡별 알송 후보, 싱크 오프셋은 기존 `settings.json`의
  `ivlyrics` 항목에 저장합니다. 기존 설정 파일도 읽을 수 있습니다.
- AI 키는 `rocks.spotifast.Spotifast` 서비스 아래 제공자별 `ivlyrics-*` 자격 증명
  항목에 저장합니다. 설정 JSON이나 로그에 저장하지 않습니다. Spotify 로그아웃은
  이 별도의 AI 키를 삭제하지 않습니다. 제거하려면 빈 키를 저장하세요.
- 알송은 네이티브 HTTP 클라이언트에서
  `http://lyrics.alsong.co.kr/alsongwebservice/service1.asmx`에 직접 SOAP 요청을 보냅니다.
  제목·가수·가사 ID가 전송되며 이 구간은 **암호화되지 않은 HTTP**입니다.
  Spicetify 프록시나 Spotify 토큰·쿠키를 사용하지 않습니다. 조회 전체 제한은 10초입니다.
- AI ON이면 가사와 번역/발음 언어를 선택한 제공자의 HTTPS API로 보냅니다.
  해당 제공자의 API 키만 인증 헤더에 사용합니다. Spotify 인증 정보는 전송하지
  않으며 키를 다른 서버로 전달할 수 있는 HTTP 리디렉션을 따르지 않습니다.
  응답 제한은 90초이며 자동 재시도는 없습니다. 제공자 요금이 발생할 수 있습니다.
- Spotifast의 기존 HTTP/SOCKS/System 프록시 설정을 따릅니다. 잘못된 프록시 설정을
  우회해 직접 연결하지 않습니다.
- 알송 캐시는 기존 가사 캐시 폴더의 `alsong-v1-*`, 번역 캐시는 `ivlyrics-ai-*`입니다.
  번역 캐시에는 원문 줄·모델·제공자·언어·발음 방식이 반영되며 API 키는 포함하지
  않습니다. 기존 가사 캐시와 함께 지워도 됩니다.

## 이번 네이티브 이식의 범위

포함: 줄 단위 싱크 가사, 알송 우선/후보 선택, 번역·발음, AI ON/OFF,
곡별 오프셋, 두/세 줄 글자 크기, 앨범 배경을 사용하는 ivLyrics 기본 전체화면.

사용자 요청에 따라 학습 모드는 제외했습니다. 웹 엔진을 넣지 않는 선택에 따라
YouTube 영상 배경, Spicetify 전용 DOM/UI, 플러그인 마켓과 자동 설치기는 제외합니다.
단어별 노래방 타이밍, 후리가나 루비 레이아웃, 커뮤니티 로그인·동기화,
가사 편집/등록·공유 이미지·별도 오버레이는 구현하지 않았습니다.
AI의 발음 표기는 원문 아래에 일반 텍스트로 표시됩니다.

이 수정은 로컬 소스에만 있습니다. 원본 Spotifast의 배포본/업데이트를 설치하면
ivLyrics 통합 코드가 들어 있지 않을 수 있으므로 이 소스에서 빌드한 파일을 사용하세요.

# Local monochrome icon

The local build uses Spotify's circular wave mark in `#303030` and white,
as requested for this customization. It does not change the app's name or
imply affiliation with Spotify.

Vector source: [Spotify logo without text](https://upload.wikimedia.org/wikipedia/commons/1/19/Spotify_logo_without_text.svg).
The original green compound path is recolored, with white behind its wave cutouts.
The mark and associated trademarks belong to Spotify.

`spotifast.svg` is the runtime source for the app, window and tray icons.
`../windows/spotifast.ico` contains 16, 24, 32, 48, 64, 128 and 256px sizes.
`../macos/icon-1024.png` is the source for the existing macOS bundle script.

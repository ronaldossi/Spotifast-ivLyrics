# v0.12.0-ivlyrics.2

검색 기록 전체 삭제, 빈 검색 화면의 추천/최근 재생 목록, 한국어 표시를 추가한 Windows 배포 리비전입니다. 앱의 기본 버전은 0.12.0입니다.

- 기존 글꼴, 색상, 카드와 목록 구성요소를 유지했습니다.
- 한국어를 포함한 기존 15개 번역 카탈로그에 새 문구를 반영했습니다.
- 사용자별 설치와 제거를 지원하는 설치파일을 제공합니다.

검증: 전체 기능 1,035개 / 기본 기능 998개 테스트 통과(각 4개 기존 ignored), 두 구성의 clippy, doctest, rustdoc, 포맷 검사 통과. Windows 설치·제거와 파일 1,004개 무결성 확인.

실제 계정의 추천 API 응답과 Linux/macOS 실행은 미검증입니다. Unix launcher 검사와 Jekyll 빌드는 Windows 환경의 도구 부재로 완료하지 못했습니다.
